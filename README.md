# Workspace Switch Checklist

Checks a move to one all-in-one workspace app against your business: seats against today's bill, where your data sits, what is missing, and a one-team trial. Macro is the worked example.

**Who it is for:** Owners tired of email, chat and docs living in separate places, before they move a whole team.

**What you need:** Claude Code or Codex and what you pay for your current tools.

## Install

Open `SETUP-PROMPT.md`, copy the prompt in it, and paste it into a new Claude Code or Codex chat. It installs this skill and starts it. It keeps your existing skills as they are.
